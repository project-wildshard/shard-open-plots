# Restore the Open Plots author proofs

CI21 PLOTS-TOOL puts the two lifted suites beside their authoring
commands. Their original imports failed before collection. Use the
public engine declaration and grid ports, and put the existing
dome-camera reader and eight camera manifests with the capture tools.
All twelve cases pass, including the real JPEG board and changed-image
refusal. The proofs need no browser or external art checkout.

Hosted CI exposed an undeclared AssemblyScript dependency in the
pinned engine's public platform script. Add it to the existing
engine 0.1.2 package extension. A fresh frozen global-store install
runs both original suites successfully.
